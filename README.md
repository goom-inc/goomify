# WORLDS — playable prototype

「観るだけじゃない。物語の住民になる。」スマホ中心の、七日間の物語体験の試作です。

## 現在の状態

**一人用・端末内保存のプロトタイプです。オンラインの共同プレイではありません。**

- 海底都市の7日間、4つの役割、毎日3つから1つの選択、状態に応じた結末。
- スマホ／PCの画面、選択の確認、広場のローカル投稿、記録のJSON保存。
- 二重選択の防止、入力の検証、投稿のHTMLエスケープ、保存失敗の表示。
- 通報・非表示は端末内の操作体験です。運営者への送信はありません。
- 体験版では「明日を見てみる」で次の日に進みます。実時間の締切はありません。
- 実際の認証、共有DB、開催者管理、自動集計、AI、決済・分配は**未実装／未接続**です。

localStorageは利用者が変更できるため、不正対策や権限制御の根拠にはできません。この実装をそのまま有料の共同プレイに使用しないでください。

## ローカル起動

Node.js 22以上を使用します。ランタイム依存パッケージはなく、`npm install` は不要です。

```sh
npm run check  # 構文確認、20テスト、静的ビルド
npm run dev    # http://127.0.0.1:4173
```

`npm run build` で公開対象だけを `dist/` に出力します。

```sh
npm run standalone
```

これは `dist/worlds-playable.html` に単一HTML版を生成します。ブラウザによってローカルファイルの保存仕様が異なるため、通常はHTTPサーバーでの利用を推奨します。PWAのマニフェストはありますが、オフライン再起動を保証するService Workerはまだありません。

## 構成

```text
index.html                入口・CSP
src/app.mjs               画面、入力、端末内保存
src/engine.mjs            決定論的なゲームルール
src/styles.css            レスポンシブUI
scripts/serve.mjs         ローカル開発サーバー
scripts/build.mjs         配信ファイルの限定コピー
scripts/standalone.mjs    単一HTML出力
tests/engine.test.mjs     Node.jsの単体テスト
tests/ui_smoke.py         Chromium画面テスト（環境制約は下記参照）
vercel.json               静的プレビューのデプロイ設定
```

今回の試作は依存関係を持たないJavaScript ES Modulesです。提案段階のReact／Supabase本番アプリが完成したという意味ではありません。ゲームのルールとUIを分け、今後のサーバー実装へ移しやすい構成にしています。

## 検証

- Node.js単体テスト：20件成功。4役割 × 3の7乗 = 8,748経路の完走と数値範囲を確認。
- Chromium 144の画面検証：15チェック成功。360／390／768／1,440px幅、参加、選択、7日間、投稿、JSON保存など。
- **画面検証は `page.set_content` でビルド済みHTMLを読み込む環境内テストです。URLナビゲーションが実行環境で制限されているため、保存・再読込・タブ間イベントは模擬しています。公開URL、ネイティブlocalStorage、iPhone Safari実機、HTTPヘッダー、バックエンド、実決済の試験ではありません。**

ブラウザ試験の再現にはPython版PlaywrightとChromiumが別途必要です。

```sh
npm run standalone
python tests/ui_smoke.py
```

## 公開

Vercel等へ `dist/` を静的配信する準備はありますが、実際の公開は別の操作です。`vercel.json` だけではデプロイされません。接続先と利用プランを確認し、有料契約や本番切替は承認後に実施します。

本番化に必要な追加実装と、デプロイ時の検証・停止方法は `docs/DEPLOYMENT.md` に記載しています。
